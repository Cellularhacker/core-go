# core-go
Common core utils across based on Cellularhacker's code written in Go.

## Usage
- How to import?
```shell
go get -u github.com/Cellularhacker/core-go
```
## ※ Important
- package name is just `core`. so you have to use like **`core.IsProductionMode()`**, not **`core-go.IsProductionMode()`.**



## Development Notes

Internal development context (design notes, work log, decisions) for this repo is maintained by the owner in a separate **private** repository — it is **not** required to use this library. Public consumers can ignore.
